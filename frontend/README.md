## Project Structure
- `src/components/Navbar.jsx`: Navigation bar with active link state.
- `src/components/AddActivityModal.jsx`: Modal with numeric 1 to 5 rating dropdown (no star icons).
- `src/pages/PlanTrip.jsx`: Travel preference form (destination, days, budget, vibe).
- `src/pages/Dashboard.jsx`: Tab switching across days, dynamic budget calculation, and live state updates.
- `src/App.css`: Responsive CSS matching your mockup.

## How to Run Locally

1. Extract the zip file to your preferred location (e.g., `Desktop\travel-planner-frontend-react`).
2. Open PowerShell or Command Prompt inside the extracted folder:
   ```powershell
   cd travel-planner-frontend-react
   ```
3. Install dependencies:
   ```powershell
   npm install
   ```
4. Start the application:
   ```powershell
   npm start
   ```
5. The application will launch at `http://localhost:3000`.
